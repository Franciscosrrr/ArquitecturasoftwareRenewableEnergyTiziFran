# Calculadora React - Entrega 2

Se sirve compilada desde el gateway con Docker Compose. Selección de catálogo MySQL, hábitos, consumo/desglose y referencia de traza. Estado solo en memoria; no usa localStorage, sessionStorage ni IndexedDB. La clave M2M no se entrega al navegador. La recomendación solar y los escenarios guardados siguen pendientes.

Para desarrollo opcional: instalar Node compatible con Vite 7, ejecutar npm ci y npm run dev; las rutas /api se envían al gateway de localhost:8080. El flujo normal y reproducible usa Docker y no necesita Node en el host. Tests del navegador: perfil verificar-e2e de Compose.

# Estructura vigente

`gateway/`: proxy/autorización/balanceo y publicación de React/contratos. `platform/`: salud, correlación, métricas, transporte AMQP y utilidades de seguridad/SQL. `services/usuarios/`: identidad/roles/sesiones. `services/consumo/internal/application/`: reglas puras; `private/`: escenarios, snapshot/transacción/outbox. `services/electrodomesticos/`: repositorio SQL y features de índice/caché/outbox. `services/solar/`: dominio, aplicación/puertos y adaptadores HTTP/Mongo/vendedor/AMQP. `frontend/`: calculadora, cuenta, comparación y administración.

`infra/`: Dockerfiles, Mongo init, Prometheus/alertas, Grafana/Loki y unidad cloud. `scripts/`: arranque, verificación y prueba pública. `tests/`: HTTP real, carga, fallas y e2 e. `docs/contracts/`: contratos procesables y ejemplos. `docs/adr/`: exactamente un archivo D1–D13 con actualizaciones dentro del mismo registro. `docs/evidence/final-2026-11-09/`: resultados finales. Los directorios de entregas anteriores son históricos; `mock/` se conserva opcionalmente y no implementa el sistema real.

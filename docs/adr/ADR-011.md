# ADR-011 - D11 - Observabilidad

Versión 1.0.0 · Entrega 2 · Estado: **Primera versión implementada: logs y trazas**. Autores: Tiziano Nicolas y Francisco Skrie. Reemplaza: ninguna.

## Contexto

Se necesita demostrar un flujo distribuido sin inspeccionar manualmente cada servicio ni exponer datos de simulación.

## Decisión

slog JSON con service, route normalizada, method, status, duration_ms, request_id, trace_id y span_id. OpenTelemetry/W3C traceparent y OTLP/HTTP a Jaeger local. Spans de gateway, Consumo, cliente interno, Electrodomésticos y consulta MySQL. Muestreo local 100%. Sin bodies, claves, SQL o valores personales. Jaeger en memoria, evidencia exportada para la entrega.

## Alternativas consideradas

Logs de texto sin correlación dificultan reconstruir operaciones; solo request_id no prueba relaciones padre/hijo; una plataforma SaaS agrega cuentas y costos innecesarios para este hito.

## Consecuencias y validación

Pendiente para la final: métricas Prometheus de tráfico/errores/latencia, circuito, pool y colas; dashboard Grafana y alerta de 5xx >5% por 5 min con tráfico mínimo. Objetivo inicial propuesto: p95 <2 s con servicio caliente a 0,5 req/s y disponibilidad 99% en ventana de demostración. Son objetivos a validar, no un SLO medido ni un acuerdo productivo.

Las evidencias ejecutadas se enumeran en [DELIVERY-2](../DELIVERY-2.md). Una decisión propuesta no se presenta como una implementación validada.
